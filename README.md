# وب‌سایت نمونه‌کار — محمد صحرانورد (نسخه‌ی ۵)

سایت استاتیک + پنل مدیریت. بدون کتابخانه، بدون مرحله‌ی build، آماده‌ی GitHub Pages.

## ساختار پوشه

```
index.html   style.css   script.js      ← سایت
admin.html   admin.css   admin.js       ← پنل مدیریت (همان پوشه)
Image/                                  ← تصاویر شما (Image-1 … Image-21، My-photo.png، Icon-*.png)  — دست‌نخورده
font/                                   ← فونت‌های Rokh (woff2)                                     — دست‌نخورده
content.json                            ← با اولین «انتشار» از پنل ساخته می‌شود (لازم نیست دستی بسازید)
```

> پوشه‌های `Image/` و `font/` داخل این بسته نیستند؛ همان پوشه‌های فعلی خودتان را کنار فایل‌ها نگه دارید. هیچ نام فایلی تغییر نکرده است.

## اجرا به‌صورت محلی

1. شش فایل بالا را کنار پوشه‌های `Image/` و `font/` بگذارید.
2. با یک سرور ساده باز کنید (Live Server در VS Code، یا `python -m http.server`). باز کردن مستقیم با `file://` هم کار می‌کند؛ فقط `content.json` خوانده نمی‌شود و محتوای داخلی نمایش داده می‌شود.

## انتشار روی GitHub Pages

1. کل پوشه (فایل‌ها + `Image/` + `font/`) را در ریشه‌ی مخزن قرار دهید و push کنید.
2. در مخزن: **Settings → Pages → Source: Deploy from a branch → Branch: main / (root)**.
3. آدرس سایت: `https://USERNAME.github.io/REPO/` — همه‌ی مسیرها نسبی هستند و زیرپوشه را درست پشتیبانی می‌کنند (تست شده).

## پنل مدیریت (`admin.html`)

- ورود: نام کاربری `mamad`؛ گذرواژه همان که توافق شد. (ورود فقط یک درگاه ظاهری است؛ امنیت واقعی با توکن گیت‌هاب است.)
- **تنظیمات → اتصال گیت‌هاب:** مخزن (`owner/repo`)، شاخه (`main`) و یک **Fine-grained PAT** با دسترسی فقط به همین مخزن و مجوز **Contents: Read & Write**.
- توکن با گذرواژه‌ی شما رمز می‌شود و فقط در مرورگر همان دستگاه (`localStorage`) می‌ماند؛ هرگز داخل فایل‌های سایت یا مخزن نوشته نمی‌شود. اگر دستگاه مشترک است، بعد از کار «خروج» بزنید یا توکن را در گیت‌هاب باطل کنید.
- «انتشار تغییرات» = یک کامیت اتمیک (تصاویر جدید + `content.json`). Pages معمولاً ۱–۳ دقیقه بعد به‌روز می‌شود.

### بخش «شبکه‌ها و لینک‌ها»

- اینستاگرام/تلگرام از «شناسه» و واتساپ از «شناسه + شماره» ساخته می‌شوند (مثل قبل).
- **لینک سفارشی:** نام + آدرس (مثلاً بهانس، دریبل، سایت دیگر). می‌توانید روشن/خاموش، ویرایش، حذف و با فلش‌ها مرتب کنید. ترتیب فهرست = ترتیب آیکن‌ها در سایت.
- در سایت، لینک سفارشی با آیکن زنجیر نمایش داده می‌شود؛ نام آن با هاور (دسکتاپ) باز می‌شود و در موبایل همیشه کنار آیکن دیده می‌شود.
- تا وقتی هیچ لینک فعالی نباشد، سایت «به‌زودی» و نقطه‌چین نشان می‌دهد؛ با اولین لینک فعال خودکار حذف می‌شود.

## ساختار داده (`content.json` — سازگار با نسخه‌ی قبل)

```json
"contact": {
  "phone": "0901…", "id": "handle", "email": "…", "lead": "…",
  "platforms": [
    { "key": "instagram", "enabled": true },
    { "key": "custom", "id": "c_ab12", "label": "بهانس", "url": "https://behance.net/…", "enabled": true },
    { "key": "telegram", "enabled": false },
    { "key": "whatsapp", "enabled": true }
  ]
}
```

فایل‌های قدیمی بدون `custom` بدون تغییر کار می‌کنند.
